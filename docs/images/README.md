## Image content and reproduction

`workspace-dark.png` and `workspace-light.png` show the same Voltron Nevera
source sample 4960, replay `01:07.39` at 50 Hz, with 11-sample smoothing and
selection 4200–5100, highlighted by a translucent band in the chart. The marker
interval remains visible. Both captures use the
English interface at 1600×1100 and show the context strip, current Ejector Airtime
and visible-range extrema. The chart fits the available height without a vertical
workspace scrollbar or capture-specific layout changes. The airtime legend sits
below the diagram, near the context strip and above sample navigation. Light
appearance uses darker context colors for contrast.

`export-preview.png` shows the native export assistant at 1500×1000, using the
same source sample and smoothing. Its five thumbnails and large Flow Ribbon
preview use the production renderer with landscape, English, transparent output,
50 fps and a 12-second time window. The checkerboard is preview-only. Captures
show the Position selector; the other thumbnails follow the selected bottom edge
using equivalent placements, rather than each layout's standalone default.
Captures use isolated temporary preferences and an export database under `.tmp/`.

Regenerate the three application screenshots and their
[`app-reference.json`](app-reference.json) settings manifest from the repository
root in native Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe .\scripts\capture_app_reference.py
```

For review without replacing the documentation images, add
`--output .tmp\app-reference-preview`. The script fixes the source hash, sample,
selection, language, appearance, font (Segoe UI, 9 pt), scale factor (1) and export
settings. It rejects a changed source recording and isolates personal preferences.
It also rejects a runtime version that differs from `project.version` before capture.
Repeated captures have identical pixels in the tested Windows/Qt environment;
different Windows, Qt or font versions may change rendering details.

Regenerate all eleven Manta reference PNGs and their sample manifest:

```powershell
.\.venv\Scripts\python.exe .\scripts\render_export_reference.py
```

The Manta generator imports the pinned source directly, prepares one unified
snapshot with the fixed smoothing recipe and passes it to the production export
API. Workspace/export-assistant captures use the actual application widgets and
their bound analysis snapshots. Reference checks use the supported APIs and
independent manifest/image expectations; no retained old runtime is an oracle.

Keep GUI captures aligned with the current application and refresh README image
descriptions when visible behavior changes. Capture the actual widgets, preserve
the original recordings and retain the existing image license and attribution.

## README detail captures

The README also uses three generated native UI details, outside the 14-image
CC BY-SA grant listed above:

- `voltron-airtime-detail.png`: Voltron Nevera sample 4960, replay `01:07.39`,
  samples 4500–5250 in view and 11-sample smoothing. The chart and its actual
  context strip/legend include Floater and Ejector labels.
- `taron-force-cards.png`: Taron sample 3399, replay `00:22.15`, with 11-sample
  smoothing. The three native cards show vertical, lateral and longitudinal
  values with their context/direction labels.
- `manta-smoothing-comparison.png`: Manta samples 4650–4900, recording seconds
  93–98, with only the vertical curve visible. Three actual chart captures use
  1, 11 and 31 samples, respectively. The force limits and category labels are
  fixed to the unfiltered view for a direct comparison; the normal workspace
  chooses its force limits for the current smoothing. The sample cursor is hidden.
  Added headings identify each window; the context strip remains visible and
  can change with smoothing.

Regenerate only these details and their source hashes/sample/axis manifest:

```powershell
.\.venv\Scripts\python.exe .\scripts\capture_app_reference.py --details
```

Add `--output .tmp\readme-details` to review without replacing documentation
images. The same isolated profile, English labels, Segoe UI font and scale factor
as the main screenshots apply; the workspace is 1280×720 in dark appearance.
[`readme-reference.json`](readme-reference.json) records the fixed scenes and the
actual axis limits for each smoothing panel. The original bytes of all three
recordings are verified before and after capture. The default command continues
to generate only the three full application screenshots.

## Workspace appearance gallery

The [appearance guide](../user/APPEARANCE.md) shows `appearance-*.png`, one image
per workspace theme except System. All use the same Voltron scene, sample,
selection, smoothing and font as the main application images.
System has no separate image because it follows Light or Dark.
Each image is captured directly from an 800×650 application content area plus
the native Windows title bar and window borders, without downscaling. These show
the normal compact workspace with the inspector hidden.
The capture window stays on top while these images are taken to prevent other
applications from obscuring it.

```powershell
.\.venv\Scripts\python.exe .\scripts\capture_app_reference.py --themes
```

[`appearance-reference.json`](appearance-reference.json) records the source hash,
scene and image filenames. Add `--output .tmp\appearance-preview` to review first.
These additional images are outside the 14-image license grant listed above.
