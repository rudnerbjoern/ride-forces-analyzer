## Image content and reproduction

`workspace-dark.png` and `workspace-light.png` show the same Voltron Nevera
source sample 4960, replay `01:07.39` at 50 Hz, with 11-sample smoothing and
selection 4200–5100, highlighted by a translucent band in the chart. The marker
interval remains visible. Both captures use the
English interface at 1600×1100 and show the context strip, current Ejector Airtime
and visible-range extrema. The chart fits the available height without a vertical
workspace scrollbar or capture-specific layout changes. The airtime legend sits
below the diagram, near the context strip and above sample navigation. Light
appearance uses darker context colors for contrast.

`export-preview.png` shows the native export assistant at 1500×1000, using the
same source sample and smoothing. Its five thumbnails and large Flow Ribbon
preview use the production renderer with landscape, English, transparent output,
50 fps and a 12-second time window. The checkerboard is preview-only. Captures
use isolated temporary preferences and an export database under `.tmp/`.

Regenerate the three application screenshots and their
[`app-reference.json`](app-reference.json) settings manifest from the repository
root in native Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe .\scripts\capture_app_reference.py
```

For review without replacing the documentation images, add
`--output .tmp\app-reference-preview`. The script fixes the source hash, sample,
selection, language, appearance, font (Segoe UI, 9 pt), scale factor (1) and export
settings. It rejects a changed source recording and isolates personal preferences.
Repeated captures have identical pixels in the tested Windows/Qt environment;
different Windows, Qt or font versions may change rendering details.

Regenerate all eleven Manta reference PNGs and their sample manifest:

```powershell
.\.venv\Scripts\python.exe .\scripts\render_export_reference.py
```

The Manta generator imports the pinned source directly, prepares one unified
snapshot with the fixed smoothing recipe and passes it to the production export
API. Workspace/export-assistant captures use the actual application widgets and
their bound analysis snapshots. Reference checks use the supported APIs and
independent manifest/image expectations; no retained old runtime is an oracle.

Keep GUI captures aligned with the current application and refresh README image
descriptions when visible behavior changes. Capture the actual widgets, preserve
the original recordings and retain the existing image license and attribution.
