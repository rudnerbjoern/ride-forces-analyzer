## Scientific limits

Strict frame admission uses absolute tolerance 1e-10, relative zero; synthetic
comparisons use 1e-14. Invalid/reflected/skewed bases are rejected without repair.
Explicit provisional calibration and source-bound unit contracts do not certify
real rider loading. Source direction rows in the candidate rider order fail
strict orthonormal admission for all five originals; the separate projection
policy normalizes rows under ADR 0006 rather than claiming an orthogonal frame.

The [API guide](../development/ANALYSIS_MODELS.md) defines models/device/frame/
extrema contracts. [Source comparisons](APP_REFERENCE.md) retain independent
numeric evidence and known discrepancies. Universal mounting/unit/epoch
qualification, analytical GPS, added filters and broad statistics remain excluded.
