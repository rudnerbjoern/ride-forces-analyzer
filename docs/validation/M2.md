## Evidence boundary

All 48,029 acceleration vectors, 39,317 available gravity vectors, 698 GPS fixes
and seven attributes are retained across the five fixtures. Exact fingerprints
and authorization belong in the [catalog](../development/RECORDINGS.md).
Missing start/end independently default to 0/N-1 with warnings; invalid supplied
indices remain errors. Defaults never insert fields into the original source.

Test ownership: service, decoder, motion, optional-data, source/recording-model,
diagnostic and fixture suites under `tests/`. Only schema 2.2.0 is supported.
Raw GPS units/sentinels/epochs, general physical calibration and source end-index
semantics remain unqualified; [source-app comparisons](APP_REFERENCE.md) qualify
only their explicit display contracts.

Local performance observations are not throughput/RAM guarantees.
Real hostile ACLs, mapped-drive locality, cold-cache performance, total process
memory and clean-machine release are not established by importer acceptance.
