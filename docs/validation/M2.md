Manta, Kraken, Taron, Voltron Nevera and Iron Gwazi remain byte-identical,
including every GPS value. Pinned size/SHA-256, before/after bytes and modification
times pass; [catalog](../development/RECORDINGS.md) and
[integrity tests](../../tests/test_project.py) retain exact filenames/digests.
All 48,029 acceleration vectors, 39,317 available gravity vectors, 698 GPS fixes
and seven attributes are retained; 462 negative GPS readings produce warnings.

Recorded Windows benchmark: `uv run python tests/benchmark_importer.py --repetitions 5`.
Five timed imports after warmup, then separate traced allocation measurements:
Path medians 128–398 ms, bytes medians 181–357 ms; Python allocation peaks
5.8–14.2 MiB for Path and 5.1–12.6 MiB for bytes. Warm filesystem cache;
preloaded bytes/native allocations are excluded. These are local observations,
not guarantees. Reproduce with the [benchmark](../../tests/benchmark_importer.py);
raw measurements remain in `.tmp/stage5-performance.json`.

## Known limits and delivery

Only schema 2.2.0 is supported. Configurable document/diagnostic budgets follow
ADR 0002. General GPS units/sentinels, epochs, physical frame calibration and end-index
semantics remain unqualified; the separate [app-reference policy](APP_REFERENCE.md)
provides source-bound projection/filtering/replay evidence. Real hostile filesystem/ACL behavior, mapped-drive
locality, cold-cache performance, total process RAM and fresh interactive editor
inspection are unverified; applicable mocks/CLI tests pass. Existing dependency
limits are documented [separately](DEPENDABOT.md).

The owner authorized delivery through PR #7 and subsequently authorized its merge
and final M2 closure. Integration into `main` uses that PR exclusively.
M3/M4 are partially implemented; current scope is in the [roadmap](../ROADMAP.md).
