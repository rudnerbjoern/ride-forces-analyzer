## Upgrade notes

Stream Deck users: update Ride Forces Analyzer to 2.1.0 and the plugin to 1.0.0
together. Confirm the updated bundled profile when Stream Deck offers it; profiles
from Analyzer 2.0.0 do not support the updated controls. If the old layout remains,
follow the [profile setup instructions](https://github.com/{{REPOSITORY}}/blob/{{TAG}}/docs/user/STREAM_DECK.md#set-up-the-controls).
