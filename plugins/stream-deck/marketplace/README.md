# Marketplace material

Publication texts, final upload images and editable design sources for the plugin.

| Folder     | Contents                                                                          |
| ---------- | --------------------------------------------------------------------------------- |
| `listing/` | Product description, additional links and release notes                           |
| `media/`   | Final icon, thumbnail and numbered gallery images                                 |
| `design/`  | Artwork notes, previews, backgrounds, prompts and the retained thumbnail proposal |

## Publication texts

- [Product description](listing/DESCRIPTION.md): English listing copy, limited to 4000 characters; URLs are removed by the editor.
- [Additional links](listing/LINKS.md): destinations for the separate Marketplace link fields.
- [Release notes 1.0.0](listing/release-notes-1.0.0.md): English text for the release-notes field, limited to 1500 characters.

## Media upload requirements

| Asset         | Format     | Dimensions                     | Maximum file size |
| ------------- | ---------- | ------------------------------ | ----------------- |
| Icon          | PNG or JPG | 288 × 288 px, 1:1 recommended  | 2 MB              |
| Thumbnail     | PNG or JPG | 1920 × 960 px, 2:1 recommended | 5 MB              |
| Gallery image | PNG or JPG | 1920 × 960 px                  | 10 MB             |
| Gallery video | MP4        | 1920 × 1080 px                 | 50 MB             |

The gallery requires at least three images or videos.
