# Plugin 1.0.0

Initial release of the Ride Forces Analyzer Stream Deck plugin.

- Browse your Library and open recordings in the current Explorer or another window.
- Control playback, speed, sample position, zoom and selections.
- Choose force curves, switch between Raw and Calibrated mode, and adjust smoothing.
- Preview, apply or discard Start, Gravity, Incline and End marker changes.
- See confirmed application state and control availability directly on your controls.

## Included profiles

- Stream Deck +: six pages with contextual dials and touch-strip feedback, including Library filters.
- Stream Deck Neo: dedicated key layouts, contextual InfoBar and native Touch Point navigation.
- Stream Deck Mobile: a reduced six-key preview with basic Library, playback and view controls.

Requires Ride Forces Analyzer 2.1.0, installed separately, and Stream Deck 7.6 or later. Enable Stream Deck integration in Analyzer and keep the intended Explorer in the foreground.
